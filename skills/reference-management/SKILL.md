# Reference Management

1. Check whether the user's Zotero local API, Zotero helper script, or exported BibTeX file is available. Do not assume ChatGPT-provided Zotero skills/scripts are installed locally.
2. Look up items by title/DOI and distinguish Zotero item keys from BibTeX citation keys.
3. Export or update .bib files without deleting existing entries. Confirm before importing references or changing Zotero collections.
4. For LaTeX, preserve existing bibliography style and use correct citation syntax for the document setup.
5. Record source DOI, URL, publisher, publication status, and date. Never synthesize citations without verified metadata.
