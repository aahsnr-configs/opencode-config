0722921d5542fc593105c27bd52630babd8b8c2a. All 161 files have matching Git blob hashes.

The Codex plugin manifest and app icon are not installed: OpenCode discovers
SKILL.md directories directly. Codex UI metadata within the skill directories
is preserved for inventory fidelity but does not add OpenChamber UI features.
The plugin is self-contained and does not require an MCP server.

Rosalind Workbench viewers or guided NGS compute, commercial provider accounts,
or other separately distributed ChatGPT plugins. Importing these files does
not grant those capabilities.
